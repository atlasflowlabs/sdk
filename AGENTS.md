# Agent notes

This repository contains `@atlasflow/sdk`, the public TypeScript SDK for the
Atlasflow REST API. It is self-contained: the committed `openapi.yaml`
snapshot goes in, the npm package comes out. No Atlasflow internal code is
needed to build it.

## Conventions

- `openapi.yaml` is a snapshot of the deployed spec at
  <https://api.atlasflow.com/v1/openapi.yaml>. Never edit it by hand. The
  `sync-spec` workflow refreshes it and opens a PR when the deployed spec
  changes.
- Files under `src/generated/` are generated by `@hey-api/openapi-ts` from
  the snapshot and must never be edited by hand. Run `npm run generate` to
  regenerate. CI fails when they are stale.
- `src/index.ts` is the only hand-written source file.
- Verify changes with `npm run typecheck`, `npm test`, and `npm run build`.

## Releasing

Bump `version` in `package.json`, merge, then push a matching `v*` tag. The
release workflow publishes to npm with provenance via trusted publishing.
